# 需求桥 · AI 需求澄清与验收助手

把客户的口语想法整理成可修改、可确认、可验收的开发需求。桌面端默认中文界面，页面自动适配窄屏。

## 本地启动

需要 Node.js 18 或更新版本，无需安装 npm 依赖。

```bash
node server.mjs
```

在浏览器打开 <http://localhost:8000>。项目只绑定到本机回环地址，不对局域网开放。

## 启用真实模型

1. 复制 `.env.example` 为 `.env`。
2. 填入模型服务的 OpenAI 兼容 Chat Completions 地址、API Key 和模型名称。
3. 重启 `node server.mjs`，页面顶栏会显示“AI 模型已连接”。

`AI_API_KEY` 只由本机 Node 后端读取，不会发送给浏览器，也不会提交到 GitHub。没配置密钥时会进入本地演示逻辑，并在界面上明确标出。

## 当前可用功能

- 自由输入初始想法，再围绕项目内容逐轮追问；已配置模型时由模型动态决定追问和需求清单。
- 维护需求描述和验收条件，允许手动编辑、删除、新增，并逐项标记待确认或已确认。
- 修改已确认的需求会自动撤销原确认状态，并写入变更记录。
- 草稿保存在当前浏览器，可导出 Markdown 需求文档。

本地演示逻辑只用于走通课堂演示流程；真实模型调用需要用户自行配置兼容的模型服务。协作邀请目前仍未接入服务器和多用户存储。
