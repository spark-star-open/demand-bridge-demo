# 需求桥 · AI 需求澄清与验收助手

一个用于课程项目演示的交互式网页原型：把客户的模糊想法逐步整理为双方可确认的开发需求和验收草稿。

## 本地运行

无需安装依赖。用 VS Code 打开本文件夹，在终端运行：

```bash
python3 -m http.server 8000
```

然后在浏览器访问 <http://localhost:8000>。

## 演示流程

1. 从“想做个活动报名网站，能报名、能签到就行”开始。
2. 回答人数上限、取消规则、名单导出和签到方式四个澄清问题。
3. 在右侧逐项确认需求，并查看自动生成的验收检查项。
4. 点击“导出需求文档”保存 Markdown 格式的需求确认草稿。

项目回答保存在当前浏览器的本地存储中。AI 对话使用预设演示逻辑，不调用外部模型或上传数据；“邀请协作”目前展示为功能预告。

## 技术

原生 HTML、CSS 和 JavaScript，无构建步骤、无第三方运行时依赖。适配桌面与窄屏浏览器。
